CẤU TRÚC DỮ LIỆU SỬ DỤNG
- TreeMap<String, List<String>> (không phân biệt hoa/thường): slang -> danh sách nghĩa. Tìm theo slang O(log n).
- HashMap<String, HashSet<String>>: index đảo (từ trong definition -> tập slang), dùng cho tìm theo definition.
- Toàn bộ cấu trúc (đã index) được lưu ra file nhị phân (serialization) để lần chạy sau nạp lên luôn, không cần index lại.
- Test 100.000 slang word: tìm theo slang < 1 ms, tìm theo definition vài ms (trường hợp xấu nhất khoảng 0.2 giây).

CÁC FILE DỮ LIỆU (thư mục data)
- slang.txt          : file gốc của đề (giữ nguyên, không sửa).
- slang_clean.txt    : file đã được chuẩn hóa cú pháp (tạo 1 lần từ slang.txt bởi hàm SlangFileFixer.fixFile).
- slang_default.dat  : cấu trúc dữ liệu đã index từ slang_clean.txt (dữ liệu mặc định ban đầu).
- slang_user.dat / slang_user.txt : tạo khi người dùng add/edit/delete; bấm Reset thì bị xóa và nạp lại dữ liệu mặc định.
- history.txt        : lịch sử tìm kiếm (tạo khi có tìm kiếm).

CÁCH CHẠY
- Giữ nguyên thư mục data nằm cạnh file SlangDictionary.jar, chạy:  java -jar SlangDictionary.jar
- Mã nguồn nằm trong thư mục src (biên dịch: javac -encoding UTF-8 *.java, hàm main nằm ở Main.java).
